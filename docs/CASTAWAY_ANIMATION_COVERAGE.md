# Castaway animation coverage

Generated from `assets/castaway/castaway_clips.json` plus what the game wires today. **Loaded is not integrated.** A clip counts as *integrated* only when a
behaviour of the castaway's own mind can trigger it and it has been seen playing in the game. "Observed" below means played by the autonomous castaway during
simulated runs of the real game (the `coverage` diagnostic in `src/castaway_new.js`); clips forced from the console are tracked separately and never counted.
Not yet checked by eye: foot sliding at every gait change, hand contact on every prop. Those checks belong to each milestone.
